# WardRail 行业落地套件（Industry Kits）

每个行业套件 = 预置 Agent 模板 + 策略包 + 部署配置 + DLP 规则 + 评测集。
实施团队按套件初始化项目，再叠加客户定制（连接器/数据），缩短实施周期 40%+。

| 套件 | 目标客户 | 预置场景 | 合规重点 |
|---|---|---|---|
| finance/ | 银行/证券/保险 | 投研助手、智能客服、合规审查 | 数据不出域、审计5年、模型备案 |
| government/ | 政企/国企 | 公文写作、热线工单、督查督办 | 等保三级、信创栈 |
| manufacturing/ | 制造集团 | 设备知识助手、质检报告、工单派单 | OT隔离、边缘部署 |
| healthcare/ | 医院/医共体 | 病历质控、随访助手 | 个保法、强脱敏 |
