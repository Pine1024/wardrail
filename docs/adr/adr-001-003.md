# ADR-001: 采用 LangGraph 作为编排内核

- 状态: 已接受
- 背景: 需要 checkpoint 断点续跑、HITL、可回放, 图结构编排表达力最强
- 决策: LangGraph 为主内核, Dify 作为业务侧低代码入口, 二者通过 Agent 注册中心互认
- 后果: 引入 LangGraph 依赖; 换取状态持久化与时间旅行调试能力

# ADR-002: 沙箱双档位 (Docker / gVisor)

- 状态: 已接受
- 决策: 默认 Docker+seccomp (ms 级启动), high/critical 风险强制 gVisor; 金融核心可升级 Firecracker
- 后果: 部署需安装 runsc; 换取不可信代码与文件操作的强隔离

# ADR-003: 模型网关基于 LiteLLM 而非自研

- 状态: 已接受
- 决策: LiteLLM Proxy 提供 100+ Provider 统一协议与路由降级, 自研插件补脱敏/配额/审计
- 后果: 受上游版本约束; 避免重复造轮子
